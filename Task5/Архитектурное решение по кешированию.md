Мотивация
Внедрение кеширования имеет целью снижение нагрузки на компоненты системы без увеличения затрат, связанных с масштабированием.

Предлагаемое решение
Наибольшую проблему на данный момент вызывает компонент MES API и связанный с ним интерефейс оператора MES.
Таким образом, с фокусом на эту проблему предлагаю внедрить кеширование списка заказов по max-age и delta fetching. 
Данное решение имеет низкую цену реализации, при этом значительно снизит нагрузку на сервис MES API и БД MES.

Выбор инструментов для реализации оставить за разработчиками. Как пример, [Delta](https://github.com/SimonCropp/Delta).

Решение о кешировании других сервисов следует вынести по результатам мониторинга системы.
